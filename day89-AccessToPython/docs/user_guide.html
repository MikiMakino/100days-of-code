Access → pandas 変換アシスタント

Day 89 / 100 Days of Code  |  2026-03-09

AccessのSQLクエリやVBAモジュールをPythonへ移行するための支援ツールです。 「完全自動変換」ではなく、たたき台コードを素早く生成してCopilotや手修正につなげることを目的としています。

Python 3.13 Streamlit 1.50 pandas 2.x pywin32（エクスポート機能）
💡
SQL変換機能（Tab 1）はAccess・pywin32 なしで動きます。
エクスポート機能（Tab 2）はWindows + Microsoft Access がインストールされている環境が必要です。

セットアップ

1
Python 3.10 以上をインストール python.org からダウンロードしてインストールします。
2
依存ライブラリをインストール 
pip install -r requirements.txt

または個別に:

pip install streamlit pandas numpy pywin32
3
（エクスポート機能を使う場合）Microsoft Access の確認

Microsoft Access がインストールされていることを確認してください。Access Runtime でも動作します。

起動方法

streamlit run app.py

ブラウザで http://localhost:8501 が開きます。

SQL変換タブ — 基本的な使い方

1
AccessのSQLを貼り付ける

Accessのクエリデザインビューで「SQLビュー」に切り替え、SQL文をコピーして左の入力欄に貼り付けます。

2
「▶ pandas コードに変換」ボタンを押す

右側にpandasコードのたたき台が生成されます。

3
コードをダウンロードして手修正する

「📥 コードをダウンロード」ボタンで .py ファイルをダウンロードできます。CSVファイル名やWHERE条件を実際のデータに合わせて修正してください。

⚠️
生成されたコードはたたき台です。実際に動かすには手修正が必要な場合があります。特に WHERE 条件・IIf の条件式・日本語列名まわりは確認してください。

内蔵サンプルクエリ

サイドバーから以下のサンプルを選んで変換を試せます。

サンプル名内容
抽出クエリ（WHERE + ORDER BY）基本的な WHERE / ORDER BY の変換
結合クエリ（LEFT JOIN）2テーブルの LEFT JOIN + 計算列
集計クエリ（GROUP BY）Sum / Count + GROUP BY + 日付条件

変換例：LEFT JOIN + 計算列

Access SQL
SELECT
    o.OrderID,
    o.Quantity,
    p.UnitPrice,
    o.Quantity * p.UnitPrice AS Amount
FROM Orders AS o
LEFT JOIN Products AS p
    ON o.ProductCode = p.ProductCode
WHERE o.Status = "未処理"
ORDER BY o.OrderDate;
pandas コード（生成）
import pandas as pd

orders = pd.read_csv("Orders.csv")
products = pd.read_csv("Products.csv")

df = orders.merge(
    products,
    left_on="ProductCode",
    right_on="ProductCode",
    how="left"
)

# --- WHERE ---
df = df[df["Status"] == "未処理"].copy()

# --- 計算列 ---
df["Amount"] = df["Quantity"] * df["UnitPrice"]

# --- ORDER BY ---
df = df.sort_values("OrderDate", ascending=True)

result = df[['OrderID', 'Quantity',
             'UnitPrice', 'Amount']]
print(result.head(20))

変換のコツ

💡 CSVファイル名を確認する

テーブル名から テーブル名.csv が自動生成されます。実際のファイル名やパスに合わせて修正してください。

# 生成例（修正前）
orders = pd.read_csv("Orders.csv")

# 修正後（実際のパスへ）
orders = pd.read_csv("C:/data/受注データ.csv")
💡 IIf の条件式は手修正が必要

IIf(Region = "東京", "首都圏", "その他") のような単純な比較は np.where() に変換されますが、条件式内の変数名は df["列名"] 形式に手修正が必要です。

# 生成例（修正前）
df["Area"] = np.where(Region = "東京", "首都圏", "その他")

# 修正後
df["Area"] = np.where(df["Region"] == "東京", "首都圏", "その他")
💡 WHERE条件が複雑な場合

ANDやORが組み合わさった複雑な条件は & / | に変換されますが、括弧の追加が必要な場合があります。

# 複数条件の正しい書き方
df = df[(df["Status"] == "未処理") & (df["Amount"] > 1000)].copy()

Accessエクスポートタブ — 機能概要

AccessのCOM（Component Object Model）を経由して、Accessファイル内のオブジェクトをテキストファイルに書き出します。

⚠️
動作条件
  • Windows 10/11
  • Microsoft Access がインストールされていること（Access Runtime も可）
  • pip install pywin32 が完了していること
オブジェクト種別出力先内容
クエリqueries/クエリ定義テキスト（SaveAsText）
VBAモジュールmodules/モジュールのVBAコード
フォームforms/フォーム定義テキスト
レポートreports/レポート定義テキスト
マクロmacros/マクロ定義テキスト
テーブル定義tables/ + まとめCSVフィールド名・型・サイズ・必須フラグ
クエリSQL一覧all_queries_sql.csv全クエリのSQL文をCSVにまとめる

エクスポートの使い方

1
「📦 Accessエクスポート」タブを開く
2
Accessファイルのパスを入力する 
C:\work\sample.accdb

出力先フォルダは省略可能です（省略時: ファイルと同じ場所に export_ファイル名/ を作成）

3
エクスポートするオブジェクトをチェックする

「クエリ」「VBAモジュール」「テーブル定義」は最初からオンになっています。

4
「エクスポート後にpandasコードも変換する」オプション

チェックを入れると、クエリのエクスポート後にpandasコードへの変換も自動で行います。

5
「📦 エクスポート実行」ボタンを押す

進捗がリアルタイムで表示されます。完了後に出力ファイル一覧が表示されます。

CLI: export_access.py

Streamlit UIを使わずコマンドラインから実行する場合:

# 全オブジェクトをエクスポート
python export_access.py C:\work\sample.accdb

# 出力先を指定
python export_access.py C:\work\sample.accdb --out C:\export

# 種別を絞る（クエリとモジュールのみ）
python export_access.py C:\work\sample.accdb --type query module

# テーブル定義のみ
python export_access.py C:\work\sample.accdb --type table

オプション

オプション内容
--out <フォルダ>出力先フォルダ（省略時: ファイルと同じ場所）
--type <種別>query / module / form / report / macro / table / all

CLI: batch_convert.py

エクスポートしたクエリSQLをpandasコードに一括変換:

# CSVから変換
python batch_convert.py export_sample/all_queries_sql.csv

# queries/フォルダから変換
python batch_convert.py export_sample/queries/

出力先: 入力ファイルと同じフォルダ内の converted_python/

未対応・注意事項

❌
変換対象外のSQL種別
  • UPDATE / DELETE / INSERT INTO クエリ
  • TRANSFORM（クロス集計クエリ）
  • SQL Passthrough クエリ（外部DBへのクエリ）
⚠️
手修正が必要なケース
  • Nz() / Format() / DateDiff() / Mid() などのAccess独自関数
  • IIf の条件式内の変数名（df["列名"] 形式への修正が必要）
  • フィールド名に日本語・スペース・記号が含まれる場合
  • クエリが何段もネストしている場合
  • & を使った文字列連結（Pythonでは + または f-string）
ℹ️
フォームとレポートについて
エクスポートは可能ですが、フォームのイベント処理・UI操作・VBA依存の処理は変換対象外です。 Streamlit や Flet でのUI再構築は手動で設計する必要があります。

FAQ

Q. Access がない PC でも SQL変換は使えますか？
はい。SQL変換タブ（Tab 1）は streamlit pandas numpy のみで動作します。pywin32 や Microsoft Access は不要です。
Q. エクスポート実行中にエラーが出ました
よくある原因:
  • Accessファイルが別のプロセスで開かれている → 閉じてから実行
  • パスに日本語が含まれる → 英語パスに移動してから実行
  • pywin32 がインストールされていない → pip install pywin32
  • Microsoft Access がインストールされていない
Q. テーブルのデータ（レコード）は出力できますか？
このツールはテーブル定義のエクスポートが対象です。レコード（データ）のエクスポートは Access の「外部データ → Excelにエクスポート」や pyodbc を使ってください。
Q. 変換精度を上げるにはどうすればいいですか？
生成されたコードをGitHub CopilotやClaude に渡して「このコードの問題点を修正して」と依頼するのが最も効率的です。特に IIf の条件式・複合WHERE条件・未対応関数の変換に有効です。
