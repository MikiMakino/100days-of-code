# FTP クライアント GUI アプリ

Day 90 - Python アプリ開発チャレンジ

メインフレーム向け FTP 転送ツール。データセット名の直接指定・世代ファイル（GDG）のダウンロードに対応したデスクトップアプリです。

---

## 機能要件

### 接続管理
- ホスト / ポート / ユーザー / パスワード / パッシブモード を指定して接続・切断
- 接続情報をプロファイルとして保存し、次回起動時に自動入力

### 通常転送（ファイルブラウザ）
- ローカルペイン・リモートペインの 2 ペイン表示
- ダブルクリックでディレクトリ移動
- アップロード：ローカルで選択したファイルをリモートへ転送（`STOR`）
- ダウンロード：リモートで選択したファイルをローカルへ保存（`RETR`）
- リモートのファイル・フォルダ削除
- ドラッグ＆ドロップ転送（ペイン間ドラッグ / エクスプローラーからドロップ）

### DSN 直接転送（メインフレーム用）
- データセット名（例: `HLQ.SALES.DATA`）を直接入力して UL / DL
- アップロード: `STOR 'HLQ.SALES.DATA'`
- ダウンロード: `RETR 'HLQ.SALES.DATA'`

### GDG 世代ファイル DL（メインフレーム用）
- データセット名を入力すると最新世代 `(0)` を自動付与してダウンロード
- 実行コマンド: `RETR 'HLQ.SALES.DATA(0)'`

### 転送制御・ログ
- 転送中のプログレスバーと転送量表示
- キャンセルボタン（転送中止）
- カラーログ（成功 / エラー / 情報 / 警告）

## メインフレーム FTP について

メインフレーム（z/OS）の FTP でデータセットを操作する場合、データセット名をシングルクォートで囲む必要があります。

| 操作 | FTP コマンド |
|------|-------------|
| データセット DL | `RETR 'HLQ.DATASET.NAME'` |
| データセット UL | `STOR 'HLQ.DATASET.NAME'` |
| GDG 最新世代 DL | `RETR 'HLQ.DATASET.NAME(0)'` |

**DSN 直接転送パネル** および **GDG 世代 DL パネル** がこの形式に対応しています。
