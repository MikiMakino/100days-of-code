概要

メインフレーム（z/OS）向け FTP 転送ツールです。データセット名の直接指定・ 世代ファイル（GDG）のダウンロードに対応した Python 製デスクトップアプリです。

💻 ローカル ↔ リモート

2ペイン表示でダブルクリックによるディレクトリ移動、ファイルのUL/DL/削除が可能です。

📋 DSN 直接転送

データセット名を直接入力し、STOR 'DSN' / RETR 'DSN' 形式で転送します。

🗂 GDG 世代DL

データセット名を入力すると最新世代 (0) を自動付与してダウンロードします。

📁 プロファイル保存

接続情報を JSON に保存し、次回起動時に自動入力します。

起動方法

動作環境

項目要件
Python3.10 以上（標準ライブラリのみ使用）
OSWindows（tkinter 標準搭載）
外部ライブラリ不要

起動コマンド

python main.py
ℹ️ 初回起動 接続情報が未保存の場合、各フィールドはデフォルト値（ホスト: ftp.example.com、ポート: 21、ユーザー: anonymous）で表示されます。

接続・切断

1
接続情報を入力する

ウィンドウ上部の接続パネルに ホスト・ポート・ユーザー・パスワード を入力します。

2
パッシブモードを選択する（必要な場合）

ファイアウォール環境では パッシブ チェックボックスをオンにします（デフォルト: オン）。

3
「接続」ボタンをクリック

接続に成功するとタイトルバー右の ● が点灯し、リモートペインにファイル一覧が表示されます。

4
切断するには「切断」ボタンをクリック

接続中はボタンが「切断」に変わります。

フィールド説明デフォルト
ホストFTP サーバーのホスト名または IP アドレスftp.example.com
ポートFTP ポート番号21
ユーザーFTP ユーザー名anonymous
パスワードFTP パスワード（表示は *** マスク）（空）
パッシブパッシブモード ON/OFFON

ファイルペイン

画面中央に ローカル（左） と リモート（右） の 2 ペインが並びます。

💻 ローカルペイン

「参照」ボタンでフォルダを選択します。ダブルクリックでディレクトリ移動できます。.. をダブルクリックで親フォルダへ戻ります。

🌐 リモートペイン

接続後に自動取得・表示されます。「更新」で再取得、「↑ 上へ」で親ディレクトリへ移動します。ダブルクリックでディレクトリ移動も可能です。

アイコン種別
📁ディレクトリ
📄ファイル

通常転送（ファイルブラウザ）

ペイン間のファイル転送は以下の手順で行います。複数ファイルを選択（Ctrl クリック / Shift クリック）して一括転送できます。

⬆ アップロード

1
ローカルペインでファイルを選択

Ctrl クリックで複数選択できます。フォルダはアップロードできません。

2
「⬆ アップロード」ボタンをクリック

リモートの現在ディレクトリへ転送されます。進捗はプログレスバーとログで確認できます。

⬇ ダウンロード

1
リモートペインでファイルを選択
2
「⬇ ダウンロード」ボタンをクリック

ローカルペインの現在フォルダへ保存されます。

🗑 削除

リモートペインでファイルまたはフォルダを選択し「🗑 削除」をクリックします。確認ダイアログが表示されます。

⚠️ 注意 削除した後はサーバー側のデータが消えます。事前にバックアップを確認してください。

転送のキャンセル

転送中は「キャンセル」ボタンが有効になります。クリックすると現在のファイルの転送後に停止します。

DSN 直接転送（メインフレーム用）

メインフレーム（z/OS）のデータセットを直接指定してアップロード・ダウンロードします。 ファイルブラウザを使わず、データセット名を直接入力する方式です。

ℹ️ z/OS FTP の仕様 z/OS の FTP ではデータセット名をシングルクォートで囲む必要があります（例: 'HLQ.SALES.DATA'）。このパネルが自動的にクォートを付加します。

⬆ DSN アップロード

1
データセット名を入力

例: HLQ.SALES.DATA（クォートは不要、自動で付加されます）

入力するとプレビューに実行コマンドが表示されます。

→ UL: STOR 'HLQ.SALES.DATA' / DL: RETR 'HLQ.SALES.DATA'
2
UL ローカルファイルを選択

「参照」ボタンでアップロードするファイルを選びます。

3
「⬆ DSN UL」ボタンをクリック

内部的に STOR 'HLQ.SALES.DATA' を実行します。

⬇ DSN ダウンロード

1
データセット名を入力

例: HLQ.SALES.DATA

2
DL 保存先フォルダを選択

「参照」ボタンでローカルの保存先を選びます。

3
「⬇ DSN DL」ボタンをクリック

内部的に RETR 'HLQ.SALES.DATA' を実行します。保存ファイル名はデータセット名の最終ノード（例: DATA）になります。

操作FTP コマンド
DSN アップロードSTOR 'HLQ.SALES.DATA'
DSN ダウンロードRETR 'HLQ.SALES.DATA'

GDG 世代DL（メインフレーム用）

GDG（Generation Data Group）は世代管理されたデータセットです。 (0) が最新世代を指します。このパネルはデータセット名を入力するだけで 最新世代を自動的にダウンロードします。

💡 世代番号について (0) = 最新世代、(-1) = 1世代前、(-2) = 2世代前。 このパネルは常に最新世代 (0) をダウンロードします。

使い方

1
データセット名を入力

例: HLQ.SALES.DATA
入力すると (0) ラベルと実行コマンドのプレビューが表示されます。

→ FTP実行: RETR 'HLQ.SALES.DATA(0)'
2
保存先フォルダを選択

「参照」ボタンでローカルの保存先を選びます。

3
「⬇ GDG DL」ボタンをクリック

内部的に RETR 'HLQ.SALES.DATA(0)' を実行します。

入力実行コマンド保存ファイル名
HLQ.SALES.DATA RETR 'HLQ.SALES.DATA(0)' DATA（最終ノード）
SYS1.PROCLIB RETR 'SYS1.PROCLIB(0)' PROCLIB

ログのクリア

ログ右上の「クリア」ボタンでログを消去できます。

転送のキャンセル

転送中にプログレスバー右の「キャンセル」ボタンをクリックすると転送を中止できます。

プロファイル保存

接続情報（ホスト・ポート・ユーザー・パスワード・パッシブモード）を JSON ファイルに保存できます。次回起動時に自動で読み込まれます。

保存方法

接続パネル右端の「💾 保存」ボタンをクリックします。ftp_profile.json に保存されます。

⚠️ セキュリティ注意 パスワードは 平文（暗号化なし）で保存されます。共有 PC やバージョン管理に登録する際は取り扱いに注意してください。ftp_profile.json を .gitignore に追加することを推奨します。

保存されるファイル

{
  "host":    "ftp.example.com",
  "port":    "21",
  "user":    "user01",
  "passwd":  "password",
  "passive": true
}

FTP コマンド早見表

メインフレーム FTP で使用されるコマンドの一覧です。

操作FTP コマンドパネル
通常ファイル UL STOR /path/to/file ファイルブラウザ
通常ファイル DL RETR /path/to/file ファイルブラウザ
データセット UL STOR 'HLQ.DATASET' DSN 直接転送
データセット DL RETR 'HLQ.DATASET' DSN 直接転送
GDG 最新世代 DL RETR 'HLQ.DATASET(0)' GDG 世代DL
💡 データセット名の形式 z/OS のデータセット名は HLQ.MID.LOW のようにピリオドで区切られた階層構造です。 各ノードは 1〜8 文字の英数字（先頭は英字）で構成されます。
