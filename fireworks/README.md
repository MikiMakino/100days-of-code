# 🎆 花火アプリ (Fireworks App)

Pythonと pygame で作った花火シミュレーター。クリックやキーボードで打ち上げる花火がパーティクルとなって爆発します。

## 機能

- マウスクリック：クリックした位置から花火を打ち上げ
- スペースキー：ランダムな位置に花火を打ち上げ
- ESCキー：終了
- 2〜4秒間隔で自動打ち上げ
- 半透明の残像効果による軌跡演出

## セットアップ

```bash
pip install -r requirements.txt
python app.py
```

## 動作環境

- Python 3.8+
- pygame 2.x
- Windows（フォントに Meiryo を使用）

## 学んだこと

- `pygame.SRCALPHA` を使ったアルファブレンド（軌跡の透過表現）
- パーティクルシステムの設計（生存時間管理・リスト操作）
- フルスクリーン対応（`get_size()` で実解像度を取得）
- 毎フレームのリソース生成を避けるパフォーマンス最適化（`SysFont` を `__init__` に移動）
