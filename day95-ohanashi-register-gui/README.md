# おはなしレジアプリ（tkinter版）

ターミナルで動かしていた「おはなしレジアプリ」を、  
tkinter を使ってウィンドウアプリとして動かせるようにしたサンプルです。

ウィンドウの中で、CLIと同じように質問に答えていくと、お会計を表示します。

---

## 動作環境

| 項目 | 内容 |
|------|------|
| Python | 3.8 以上 |
| 外部ライブラリ | なし（標準ライブラリのみ） |
| 対応OS | Windows / macOS / Linux |

> **macOS をお使いの場合**  
> tkinter は Python 本体とは別にインストールが必要なことがあります。  
> `python3 -m tkinter` を実行してウィンドウが開けば問題ありません。  
> 開かない場合は `brew install python-tk` を試してください。

## 使い方

```bash
# macOS / Linux
python3 ohanashi_register_gui.py

# Windows
python ohanashi_register_gui.py
```

ウィンドウが開いたら、下の入力欄に文字を入れて **Enter キー** または **送信ボタン** を押してください。  
質問に順番に答えていくと、お会計が表示されます。

### 入力の流れ

```
おはなしレジアプリへようこそ！

お客さんの名前を入力してください:
  > さくら

商品名を入力してください:
  > えほん

1つの値段（円）を入力してください:
  > 1200

個数を入力してください:
  > 3

会員ですか？ (y/n):
  > y

--- お会計 ---
さくらさん、ありがとうございます。
商品: えほん
区分: 会員
小計: 3600円
会員割引: -360円
まとめ買い割引: -100円
合計: 3140円
またおはなしの世界へどうぞ！
```

---

## 割引ルール

| 条件 | 割引 |
|------|------|
| 会員 | 小計の 10% 引き |
| 3個以上購入 | さらに 100 円引き |

---

## CLI版との違い

| | CLI版 | GUI版（このファイル） |
|---|---|---|
| 出力 | `print()` | ScrolledText に追記 |
| 入力 | `input()` | Entry ウィジェット + Enter キー |
| 流れの制御 | 上から順に実行 | `step` 変数で現在の質問を管理 |
| エラー処理 | クラッシュする | 同じ質問をやり直す |

CLIと同じ会話の流れを、`step` という変数で「今どの質問か」を管理することで再現しています。  
計算ロジック（`calculate_total()`）はCLI版と同じコードをそのまま使っています。
