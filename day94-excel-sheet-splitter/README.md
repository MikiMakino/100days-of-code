# Excel シート分割ツール

複数のシートを持つ Excel ブックから、シートを1枚ずつ個別の `.xlsx` ファイルに分割するGUIツールです。

## 機能

- ファイル選択ダイアログで元の Excel ファイルを指定
- シートを3種類に振り分け
  - **分割対象** — 1シート＝1ファイルとして出力
  - **共通シート** — 全出力ファイルに含める
  - **除外シート** — どのファイルにも含めない
- 進捗バーで処理状況を表示
- 指定フォルダに `.xlsx` ファイルを出力

## 動作環境

- Windows（Excel がインストールされていること）
- Python 3.10 以上

## セットアップ

```bash
pip install -r requirements.txt
```

## 使い方

```bash
python ex.py
```

1. 「参照...」で元の Excel ファイルを選択
2. 「シート読み込み」でシート一覧を表示
3. リストからシートを選択し、ボタンで「共通」「除外」へ移動
4. 出力先フォルダを確認（自動入力済み）
5. 「実行」ボタンで分割開始

## テスト用 Excel の生成

```bash
python create_test_excel.py
```

`test_book.xlsx`（6シート構成）が生成されます。

| シート名 | 種別 |
|---|---|
| 共通シート | 共通シートとして使用 |
| 除外シート_マスタ | 除外シートとして使用 |
| A社 〜 D社 | 分割対象（4ファイル出力） |

## ファイル構成

```
ex.py                  # メインツール（GUI）
create_test_excel.py   # テスト用 Excel 生成スクリプト
requirements.txt       # 依存パッケージ
```
